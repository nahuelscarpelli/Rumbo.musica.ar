# /public/galeria/vivo

Fotos **en vivo** para la galería filtrable.

## Archivos esperados

Mínimo **4 fotos**, ideal **6–10**.

- Formato: vertical **4:5** (ej. 1200×1500) o apaisado **16:9** (1920×1080).
- Mínimo 800px en el lado más corto. JPG.
- Nombrar como: `vivo-01.jpg`, `vivo-02.jpg`, `vivo-03.jpg`, …

> Una vez subidos los archivos, borrar este README.
