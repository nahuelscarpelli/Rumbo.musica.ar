# /public/galeria

Fotos para la galería del sitio. Sin subdivisiones — una sola colección.

## Archivos esperados

Mínimo **8 fotos**, ideal **12+**. Mezcla libre de vivo / estudio / prensa.

- Formato: vertical **4:5** (ej. 1200×1500) o apaisado **16:9** (1920×1080).
- Mínimo 800px en el lado más corto. JPG.
- Nombrar como: `galeria-01.jpg`, `galeria-02.jpg`, `galeria-03.jpg`, …

> Una vez subidos los archivos, borrar este README.
