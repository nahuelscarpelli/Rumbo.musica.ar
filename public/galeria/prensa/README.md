# /public/galeria/prensa

Fotos de **prensa / sesión fotográfica oficial**.

## Archivos esperados

Mínimo **4 fotos**, ideal **6–10**.

- Formato: vertical **4:5** (ej. 1200×1500) o apaisado **16:9** (1920×1080).
- Mínimo 800px en el lado más corto. JPG.
- Nombrar como: `prensa-01.jpg`, `prensa-02.jpg`, `prensa-03.jpg`, …

> Estas son las fotos "editoriales" — retratos grupales, fotos cuidadas para medios.

> Una vez subidos los archivos, borrar este README.
